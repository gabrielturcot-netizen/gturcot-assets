# Brigitte Bond : logo final (direction « Deux encres »)

Deux B, cyan et magenta, dont la superposition crée une troisième couleur, comme sur une presse.
Aperçu complet : `planche_identite.png`.

## Quel fichier pour quel usage

| Usage | Fichier |
|---|---|
| Imprimeur (cartes, dépliants, enseigne) | `pdf/bb_horizontal_couleur.pdf` ou `pdf/bb_vertical_couleur.pdf` (vectoriel, CMJN) |
| Carte d'affaires | `pdf/bb_vertical_couleur.pdf` au recto · `pdf/bb_symbole_inverse.pdf` au verso, sur fond noir |
| Tampon, gravure, facture noir et blanc | `pdf/bb_horizontal_noir.pdf` · sous 25 mm : `pdf/bb_symbole_noir-plein.pdf` |
| Word, courriel, signature | `png/bb_horizontal_couleur.png` (fond transparent) |
| Photo de profil Facebook / Instagram / Google | `png/bb_avatar-rond_couleur.png` |
| Site web | `svg/bb_horizontal_couleur.svg` + dossier `favicon/` |
| Canva, Illustrator, Inkscape | dossier `svg/` (le texte est déjà vectorisé, aucune police à installer) |
| Sur une photo ou un fond foncé | versions `_inverse` |

## Versions

- **horizontal** : logo principal.
- **vertical** : formats carrés et cartes d'affaires.
- **horizontal-compact** : sans slogan, pour les petits formats.
- **symbole** : les deux B seuls.
- **icone / avatar-rond / favicon** : formats carrés pour les écrans.
- Chaque version existe en **couleur**, **noir** (une seule encre) et **inverse** (fond foncé).

## Tailles minimales

| Version | Minimum |
|---|---|
| Horizontal avec slogan | 58 mm de large |
| Vertical avec slogan | 41 mm de large |
| Plus petit que ça | version compacte sans slogan |
| Symbole une encre « contour » | 25 mm, sinon la variante « noir-plein » |
| Zone de protection | la moitié de la largeur d'un B, tout autour |

## Nom d'entreprise

« Brigitte Bond » est le nom de la travailleuse autonome : il contient son prénom et son nom de famille, donc aucune immatriculation au Registraire des entreprises du Québec n'est requise. « Impression graphique » est un slogan descriptif, pas une partie du nom. Pour exploiter sous un autre nom (ex. « Bond Impression »), il faudrait s'immatriculer.
